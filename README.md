# KeylessAgent

**A coding agent that runs on your own DeepSeek login. No API key.**

KeylessAgent is a .NET coding agent that does not use an API key. It rides on the DeepSeek web chat **you are already logged into** in your own Chrome: it opens a new chat, sends your request together with your project's tree and code dump, waits for the reply, and applies it to your workspace as a strict command language (AgentScript) — on a protected agent branch, never on `main`.

## ⚠️ Terms-of-service and account-risk notice (read this first)

KeylessAgent automates a web UI. **This may violate DeepSeek's Terms of Use and can get your account limited, throttled or banned.** The selectors that drive the page can break with any site update. This project is **not affiliated with DeepSeek** — the name is used only to describe compatibility. Use it at your own risk, on an account you accept losing.

## What and why

Every LLM coding tool wants an API key. If you already pay for (or use) DeepSeek's web chat, KeylessAgent turns that login into your agent backend:

- **No API key, no billing setup.** The browser session you already have is the credential.
- **Strict command language.** The model's reply must parse as [AgentScript v1](docs/agentscript-spec.md); anything else is rejected and re-requested automatically. Nothing outside the grammar ever executes.
- **Workspace-aware.** Every request carries `tree-view-result.txt` and `code-dump-result.md` (generated by the two `.bat` files in your repo), so the model sees your actual project — filtered for noise, chunked to fit.
- **Loop with feedback.** After each executed batch the agent sends per-command results (`[KEYLESSAGENT RESULTS]`) back to the same chat, so multi-step tasks iterate until `@@done`.
- **Safety in code, not in the prompt.** Protected-branch guard, path sandbox, command policy, backups, approval modes — all enforced in C#, covered by tests.

## Requirements

- Windows (the workspace scripts are `.bat`; see [known limitations](#known-limitations))
- [.NET 10 SDK / runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
- Chrome, started with remote debugging:
  `chrome --remote-debugging-port=9222` (or let KeylessAgent launch a persistent profile automatically)
- A DeepSeek account logged in to [chat.deepseek.com](https://chat.deepseek.com) in that browser
- The two workspace scripts in your repo root: `tree-view.bat` and `code-dump.bat` (they generate the attachments; KeylessAgent never modifies them)

## Installation

KeylessAgent is a .NET global tool:

```bash
dotnet tool install --global ImanSoftware.KeylessAgent.Cli
```

Verify:

```bash
keyless --help
```

## Usage

Run one task:

```bash
keyless run "Add xUnit tests for the markdown parser"
```

Or start an interactive session (each finished turn reuses the same chat):

```bash
keyless
```

Example output of one turn:

```text
────────────────────────────────────────────── KeylessAgent
Workspace: G:\Projects\MyApp
ℹ Ctrl+C cancels the turn.
⠋ WaitingForReply reply 1
╭─ DeepSeek says ───────────────────────────────╮
│ I will add the tests now.                     │
╰───────────────────────────────────────────────╯
…diffs, command results…
✓ Turn 1 finished on branch agent/20260101-0930-add-markdown-tests
Commits:
  • 3f2a9b1 Add MarkdownParserTests
```

Other commands:

```bash
keyless resume "continue with the failing test"   # next request in the saved chat
keyless undo                                      # restore the newest .agent/backups batch
keyless config                                    # show / create keyless.json
keyless run "..." --dry-run                       # print what would happen, execute nothing
keyless run "..." -v                              # write .agent/logs/diagnostics.log
```

The first time a command runs in a workspace it creates `keyless.json` (configuration) and `selectors.json` (editable chat selectors) — see [docs/configuration.md](docs/configuration.md).

## How it works

```mermaid
flowchart TD
    A[keyless run '<request>'] --> B[Load keyless.json]
    B --> C{Git preconditions}
    C -->|not a repo| Z[Stop]
    C -->|dirty tree| D{{continue / stash / cancel}}
    C -->|protected branch| E[Create agent/ branch]
    C --> ok[Continue]
    D --> E
    E --> F[Run tree-view.bat + code-dump.bat if stale]
    F --> G[Open or resume the DeepSeek chat\nDeepThink + Search toggles checked]
    G --> H[Send system prompt first time\n+ request + filtered attachments]
    H --> I[Wait for the final answer\n(never the reasoning block)]
    I --> J{Valid AgentScript v1?}
    J -->|no| K[Send FORMAT ERROR correction] --> I
    J -->|yes| L[Execute say + up to N commands\nskipped ones reported]
    L --> M{@@done received?}
    M -->|no| N[Send KEYLESSAGENT RESULTS\nper command number/name/target] --> I
    M -->|yes| O[Refresh snapshot bat files]
    K -.retries exhausted.-> O
    N -.iteration limit.-> O
```

The full loop, limits and error codes are documented in [docs/agentscript-spec.md](docs/agentscript-spec.md).

## AgentScript in 30 seconds

The model answers in blocks; anything else is rejected:

```text
@@say
<<<MSG
Adding the file now.
MSG>>>
@@end
@@newfile src/Foo.cs
<<<CONTENT
class Foo {}
CONTENT>>>
@@end
@@done
<<<MSG
Created src/Foo.cs.
MSG>>>
@@end
@@eof
```

Commands: `say`, `newfile`, `updatefile`, `editfile` (FIND/REPLACE, must match exactly once), `deletefile`, `readfile`, `runcommand`, `ask`, `commit`, `done`. Everything the model writes is English; file content may be any language.

## Safety model

| Layer | Enforcement |
| --- | --- |
| Protected branches | `main`, `master`, `release*` are blocked in code before any file change, commit or push ([tests](src/tests/ImanSoftware.KeylessAgent.Tests)) |
| Path sandbox | workspace-relative only; no `..`, no absolute paths, `.git`/`.agent` blocked, symlink escapes rejected |
| Command policy | deny list (format, shutdown, force-push, `git config --global`, `curl \| sh`, …) plus configurable allow list |
| Approval modes | `Ask` (confirm every runcommand/deletefile), `AutoSafe` (allow-listed only), `Auto` |
| Backups & undo | every changed file is backed up to `.agent/backups`; `keyless undo` restores the newest batch |
| Dry run | `--dry-run` executes nothing |
| Transparency | full per-turn transcript in `.agent/logs`, diffs before file changes in Ask mode |

Details: [docs/security.md](docs/security.md) and [docs/git-workflow.md](docs/git-workflow.md).

## Known limitations

- **Windows only** for now (snapshot `.bat` scripts, `tree` command). The engine itself is portable.
- **Web-UI automation is brittle**: DeepSeek can change its DOM at any time; selectors live in `selectors.json` so they can be fixed without recompiling, but they will need fixing. See [docs/browser-automation.md](docs/browser-automation.md).
- **Reply reading has not yet been verified against a live chat** (indentation of code blocks, toggle behavior, stop indicator). This is the top item to validate manually.
- No captcha solving: if a captcha appears, the agent waits for you to solve it in the browser.
- The chat's context limit ends long turns: the agent detects a dead session only indirectly (reply timeouts); a "start a new chat with a state summary" path is on the roadmap.
- `Snapshot.Mode: TreeAndChanged` currently attaches the full tree plus a hint (changed-file diffing is on the roadmap).
